# Pro EQ — запись с микрофона + FX-цепочка

Веб-приложение (PWA) для записи звука с микрофона. Звук проходит через цепочку FX-плагинов. Первый плагин — параметрический эквалайзер в стиле FabFilter Pro-Q 3 с полной поддержкой телефонов и планшетов.

## Запуск

```bash
php -S 0.0.0.0:8000 router.php     # http://localhost:8000
```

Микрофон и Service Worker работают только на `https://` или `localhost`.
Apache: `.htaccess` перенаправляет `/api/*` на `php/api.php`. Nginx: `location /api/ { try_files $uri /php/api.php$is_args$args; }` и передайте в PHP `PATH_INFO`.
Без PHP (статический хостинг) приложение тоже работает: заводские пресеты читаются из `presets/index.json`, а пользовательские хранятся в `localStorage`.

## Возможности

- **Запись**: микрофон (выбор устройства, без голосовой обработки), запись Wet (после FX) или Dry, WAV 16-bit, дубли сохраняются в IndexedDB. Воспроизведение дубля через FX-цепочку, офлайн-рендер дубля через FX, импорт аудиофайлов.
- **FX-цепочка**: добавление, удаление, порядок и bypass слотов. Плагины регистрируются в реестре (`registerPlugin` в `js/fx-chain.js`).
- **EQ**: до 24 полос, 9 типов фильтров, крутизна 6–96 дБ/окт, стерео-размещение полосы Stereo/L/R/M/S. Режимы Zero Latency (IIR) / Natural Phase / Linear Phase (FIR считается в Web Worker). Auto Gain, Spectrum Grab, анализатор Pre/Post, Undo/Redo, Copy/Paste, пресеты.
- **Мобильная версия**: bottom sheet, крутилки ≥ 80px или слайдеры, FAB, drawer, нижняя навигация, раскладки для портретной и альбомной ориентации, safe-area, лупа при перетаскивании, вибро-отклик, экономный режим (`?lowpower`).

## Жесты

| Жест | Действие |
|---|---|
| Tap по узлу | выбрать узел и открыть панель |
| 1 палец | частота/усиление (у срезов — Q) |
| Pinch по узлу / 2 пальца ↕ | Q / Gain |
| Double tap | по пустому месту — новая полоса; по узлу — сброс |
| Long press | по узлу — удалить; по пустому месту — меню |
| Флик ←/→ по узлу | сменить тип фильтра |
| Pinch по пустому месту | зум по частоте и дБ |
| 3 пальца ↓ | сбросить все полосы (можно отменить через Undo) |

## REST API

`GET/POST /api/presets`, `GET/PUT/DELETE /api/presets/{id}` (`?download=1` — скачать файлом), `GET /api/presets/export`, `POST /api/presets/import`.
Заводские пресеты (`presets/*.json`) доступны только для чтения. Пользовательские сохраняются в `presets/user/` (папка должна быть доступна PHP на запись). Домен для CORS задаётся переменной `PROEQ_CORS_ORIGIN` (по умолчанию `*`).
