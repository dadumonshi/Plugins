# Movexe — запись с микрофона и цепочка эффектов

Веб-приложение (PWA) для записи звука с микрофона. Звук проходит через цепочку FX-плагинов. Эффекты: **Movexe EQ 24** (параметрический эквалайзер) и **Movexe DeEss** (де-эссер). Оба полностью адаптированы под телефоны и планшеты.

## Запуск

```bash
php -S 0.0.0.0:8000 router.php     # http://localhost:8000
```

Микрофон и Service Worker работают только на `https://` или `localhost`.
Apache: `.htaccess` перенаправляет `/api/*` на `php/api.php`. Nginx: `location /api/ { try_files $uri /php/api.php$is_args$args; }` и передайте в PHP `PATH_INFO`.
Без PHP (статический хостинг) приложение тоже работает: заводские пресеты читаются из `presets/index.json`, а пользовательские хранятся в `localStorage`.

## Возможности

- **Запись**: микрофон (выбор устройства, без голосовой обработки), запись Wet (после FX) или Dry, WAV 16-bit, дубли сохраняются в IndexedDB. Воспроизведение дубля через FX-цепочку, офлайн-рендер дубля через FX, импорт аудиофайлов.
- **FX-цепочка**: добавление, удаление, порядок и bypass слотов. Плагины регистрируются в реестре (`registerPlugin` в `js/fx-chain.js`).
- **EQ**: до 24 полос, 9 типов фильтров, крутизна 6–96 дБ/окт, стерео-размещение полосы Stereo/L/R/M/S. Режимы Zero Latency (IIR) / Natural Phase / Linear Phase (FIR считается в Web Worker). Auto Gain, Spectrum Grab, анализатор Pre/Post, Undo/Redo, Copy/Paste, пресеты.
- **Мобильная версия**: bottom sheet, крутилки ≥ 80px или слайдеры, FAB, drawer, нижняя навигация, раскладки для портретной и альбомной ориентации, safe-area, лупа при перетаскивании, вибро-отклик, экономный режим (`?lowpower`).

## Жесты

| Жест | Действие |
|---|---|
| Tap по узлу | выбрать узел и открыть панель |
| 1 палец | частота/усиление (у срезов — Q) |
| Pinch по узлу / 2 пальца ↕ | Q / Gain |
| Double tap | по пустому месту — новая полоса; по узлу — сброс |
| Long press | по узлу — удалить; по пустому месту — меню |
| Флик ←/→ по узлу | сменить тип фильтра |
| Pinch по пустому месту | зум по частоте и дБ |
| 3 пальца ↓ | сбросить все полосы (можно отменить через Undo) |

## REST API

`GET /api/presets?plugin=eq|deesser`, `POST /api/presets`, `GET/PUT/DELETE /api/presets/{id}` (`?download=1` — скачать файлом), `GET /api/presets/export`, `POST /api/presets/import`.
Заводские пресеты (`presets/*.json`) доступны только для чтения. Пользовательские сохраняются в `presets/user/` (папка должна быть доступна PHP на запись). Домен для CORS задаётся переменной `PROEQ_CORS_ORIGIN` (по умолчанию `*`).

## Movexe DeEss

Де-эссер обрабатывает звук в AudioWorklet (`js/worklets/deesser-worklet.js`). Алгоритм детекции описан в `js/detection.js`.

- **Детекция**: ФВЧ 24 дБ/окт или полосовой фильтр → RMS-огибающая (0,3 мс / 12 мс).
  - В режиме «Одиночный вокал» уровень ВЧ-полосы сравнивается с НЧ-опорой. Если НЧ сильнее (яркая гласная), детекция ослабляется, поэтому де-эссер не срабатывает ложно и нет «шепелявости».
  - Режим «Универсальный» работает по абсолютному уровню.
- **Гейн-компьютер**: отношение ∞:1, мягкое колено (Knee) и плавный потолок (Range), затем атака/восстановление и финальное сглаживание 0,4 мс.
- **Обработка**:
  - «Разделение» — кроссовер Линквица–Райли 6/12/24/48 дБ/окт. Без срабатывания уровень не меняется; кривая подавления монотонна, без «горба» у частоты раздела.
  - «Широкополосный» — ослабляется весь сигнал.
- **Упреждение**: кольцевой буфер до 20 мс; плагин сообщает задержку для офлайн-рендера.
- **Каналы**: Стерео (со связью L/R), Mid/Side, Лев/Прав.
- **Дополнительно**: Прослушивание (слышно только удаляемое), Микс, Выход, Автопорог, Автоуровень, Обход.
- **Если нет AudioWorklet**: упрощённый режим на DynamicsCompressorNode. Внешний sidechain не реализован.

**Жесты:**
- 1 палец по узлу — частота и порог;
- 2 пальца ↕ — порог, 2 пальца ↔ — частота;
- двойное касание — обход;
- долгое нажатие — сброс (по узлу — частоты и порога, по пустому месту — выбранного параметра);
- касание — выбор параметра и открытие панели.

**Пресеты:** `GET /api/presets?plugin=deesser`. Формат плоский, как в ТЗ, плюс `"plugin": "deesser"` и `category` (Vocal, Podcast, Rap, Pop, Rock, Custom). Заводские пресеты лежат в `presets/deesser/`.
